# game-automator 使用指南

通用游戏自动化框架。**你只需要实现底层按键映射，框架负责采集/建图/寻路/导航。**

---

## 安装

```bash
git clone https://github.com/UNICORN-2887/-.git
cd -/General_Generator
pip install -e .
```

依赖：Python 3.10+、OpenCV、Flask、EasyOCR。`pip install -e .` 会自动安装核心依赖。

## 三步接入

### 第 1 步：实现底层驱动

创建一个文件 `mydriver.py`，实现 3 个方法：

```python
from game_automator.driver import AbstractDriver, Actions

class MyGameDriver(AbstractDriver):

    def execute(self, action: Actions, duration_ms: int = 100):
        """收到一个标准动作, 你映射到游戏的实际按键."""
        key = None
        if action == Actions.MOVE_N:  key = 'W'
        elif action == Actions.MOVE_S:  key = 'S'
        elif action == Actions.ATTACK: key = 'J'
        # ... 全部 17 个动作映射
        if key:
            press_and_release(key, duration_ms)

    def release_all(self):
        """释放所有按下的键 (特殊情况下调用)."""
        release_all_keys()

    def click(self, x: int, y: int):
        """在游戏画面的 (x,y) 像素坐标执行点击."""
        mouse_click(x, y)
```

**17 个标准动作**：

| 分类 | 动作 |
|------|------|
| 8 方向移动 | `MOVE_N` `MOVE_S` `MOVE_W` `MOVE_E` `MOVE_NE` `MOVE_NW` `MOVE_SE` `MOVE_SW` |
| 战斗 | `ATTACK` `DASH` |
| 技能 | `SKILL_1` `SKILL_2` `SKILL_3` `SKILL_4` |
| 交互 | `INTERACT` `CANCEL` |

如果你的游戏不止这些动作，可以提 Issue 扩展。

参考实现：`examples/deadmaze/driver.py`（DeadMaze 游戏 → Windows SendInput 按键）

### 第 2 步：建图 + 标定

确保游戏在 OBS 虚拟摄像头中正常采集。

#### 2a. 光流建图

```bash
game-automator stitch -c 1 -o mymap.jpg
```

操控角色在地图中走一圈，系统自动拼接。按键：

| 按键 | 功能 |
|------|------|
| `A` | 切换自动拼接 |
| `C` | 手动拼接一帧 |
| `S` | 保存地图 |
| `R` | 重置 |
| `Q` | 退出 |
| `Shift+WASD` | 调整裁剪框单边 |
| `IJKL` | 移动裁剪框 |
| `+/-` | 缩放裁剪框 |

或者用 Python SDK：

```python
from game_automator import OBSVideoCapture, MapStitcher

cap = OBSVideoCapture()
stitcher = MapStitcher(min_movement=25, canvas_w=10000, canvas_h=8000)
stitcher.add_frame(cap.read())  # 初始帧
while moving:
    stitcher.add_frame(cap.read())
stitcher.save("mymap.jpg")
```

#### 2b. 可达区标定

用 `reachability_map.py`（参考 DeadMaze 项目）或自制工具。输出一张二值 PNG：**255=白=可达, 0=黑=不可达**。

同时记录火堆/复活点坐标 `[x, y]` 保存为 JSON。

#### 2c. ROI 标定

```bash
game-automator calibrate -c 1 -o my_rois.json -r my_rois.json
```

浏览器打开 `http://127.0.0.1:5050/calibrate`。

或者代码方式：

```python
from game_automator import OBSVideoCapture, CalibrationServer

calib = CalibrationServer(OBSVideoCapture(), roi_file="my_rois.json")
calib.add_roi("exp", 963, 1045, 50, 25, desc="经验值")
calib.add_roi("hunger", 1714, 1048, 50, 25, desc="饱食度")
# ... 添加所有需要标定的区域
calib.start()
```

标定页面操作：点击右侧卡片选中区域 → 图上拖拽移动或 WASD 微调 → 保存。

### 第 3 步：导航

```python
from game_automator import Pathfinder, Navigator, compute_direction
from mydriver import MyGameDriver
from mylocator import get_player_position  # 你的定位实现

# 初始化
pf = Pathfinder("mymap_reachable.png", shrink=80)
driver = MyGameDriver()
nav = Navigator(pf, driver, waypoint_reach=25, deviation_threshold=100)

# 规划路径
start = (1000, 500)
goal = (2000, 800)
path = nav.set_route(start, goal)
print(f"路径: {len(path)} 个途经点")

# 导航循环
while not nav.arrived:
    pos = get_player_position()  # 你的定位
    action = nav.step(pos)
    if action:
        driver.execute(action)
```

**REST API 方式**（非 Python 语言）：

```bash
game-automator serve mymap_reachable.png
# 监听 http://127.0.0.1:5001
```

然后任何语言都能调：

```bash
curl -X POST http://127.0.0.1:5001/api/plan \
  -H "Content-Type: application/json" \
  -d '{"start":[1000,500],"goal":[2000,800]}'

curl -X POST http://127.0.0.1:5001/api/step \
  -H "Content-Type: application/json" \
  -d '{"x":1015,"y":510}'
# 返回: {"action":"MOVE_SE","arrived":false,"waypoint":[1020,520]}
```

## 核心概念

### 三种采集方式

| 方式 | 类名 | 适用场景 |
|------|------|---------|
| OBS 虚拟摄像头 | `OBSVideoCapture` | PC 游戏 (推荐) |
| 屏幕截取 | `MSSScreenCapture` | 无需 OBS, 但前台必须可见 |
| Android 模拟器 | `ADBVideoCapture` | MuMu/雷电等模拟器 |

```python
cap = OBSVideoCapture(cam_id=1)   # OBS 虚拟摄像头
cap = MSSScreenCapture(monitor=1) # 屏幕
cap = ADBVideoCapture(device="127.0.0.1:5555") # 模拟器
frame = cap.read()  # 返回 numpy BGR 数组
```

### 光流建图

`MapStitcher` 自动拼接连续的 OBS 帧为大图。原理：ORB 特征匹配计算帧间位移 → 粘贴帧到对应位置。

```python
stitcher = MapStitcher(min_movement=25, canvas_w=None, canvas_h=None)
# min_movement: 像素位移 < 此值不拼接 (避免原地抖动)
# canvas_w/h: None = 自动扩展, 设置值 = 固定画布
```

### A* 寻路

`Pathfinder` 读取二值可达图 PNG, 在降采样网格上执行 A* 搜索, 结果用贝塞尔路径平滑。

```python
pf = Pathfinder("reachable.png", shrink=80)
# shrink: 降采样因子, 值越大网格越粗
path = pf.plan((1000,500), (2000,800))
# 返回: [(1000,500), (1020,520), ...]  或 None (不可达)
```

### 导航控制

`Navigator` 接收当前位置, 返回下一步标准动作。自动处理：路标切换、偏离重规划。

```python
nav = Navigator(pf, driver, waypoint_reach=25, deviation_threshold=100)
# waypoint_reach: 到达路标的判定距离 (px)
# deviation_threshold: 偏离路径多远触发重规划 (px)
```

### 方向计算

```python
from game_automator.navigation import compute_direction

action = compute_direction(current_pos, target_pos)
# 自动从 8 个方向中选最接近的
```

## 常见问题

**Q: OBS 虚拟摄像头找不到？**
A: `OBSVideoCapture.find_obs()` 自动搜索, 或手动指定 `cam_id`。确保 OBS 工具→虚拟摄像头→已启动。

**Q: 如何适配不同分辨率？**
A: 标定页面的 ROI 坐标基于 OBS 输出分辨率 (1920x1080)。如果 OBS 缩放不同, 重新标定即可。

**Q: 导航 API 支持巡逻模式吗？**
A: 支持。调用 `nav.set_waypoints([p1, p2, p3, ...])` 设置巡逻点列表。

**Q: 如何贡献新游戏的驱动？**
A: 参考 `examples/deadmaze/`，发 PR 到 `examples/` 目录。

**Q: 可以不用 Python 吗？**
A: 可以。启动 `game-automator serve` 后通过 REST API 调用。任何语言只需发 HTTP 请求。
